# RelayCat GUI v0.2.0

发布日期：2026-10-24 · Tag：`relaycat-gui-v0.2.0` · 对比版本：v0.1.9

本次更新集中改善文件浏览、内容预览和 Git 工作流，并集成 CLI v0.1.6 的会话与工作区安全修复。

## 文件浏览与预览

- 文件树支持按路径搜索，并可从右键菜单跳转到对应文件的 Git 改动。
- 图片预览支持缩放、平移和适应窗口；文本预览新增行号、换行开关和查看全文入口。
- 切换视图时保留预览、目录展开和滚动位置；窄面板默认折叠预览，为列表留出空间。
- 忽略过期文件预览响应，避免快速切换文件时显示错误内容；SVG 预览增加 DOMPurify 二次消毒。

## Git 工作流

- 改动列表按目录分组并支持折叠，显示每个文件的新增与删除行数。
- 提交区常驻面板底部，提供最近提交信息、首行长度提示和 amend 提示。
- 历史筛选改为可折叠面板，时间使用相对格式；切换项目时清理旧项目的分支和历史引用选项。
- 冲突和进行中的 Git 操作有更明确的状态与处理入口，危险操作确认框说明具体影响。
- Git 错误按类型给出可执行提示，非 Git 仓库显示本地化说明；修复重命名统计与 Git 钩子的内容区域设置。
- 加固提交信息临时文件创建，Git 超时后回收子进程组，避免命令永久挂起。

## 桌面体验与安全

- 增加工作区入口悬停标签、首次使用提示、键盘操作和空状态下一步指引。
- 面板头部显示当前分区与规模，改善窄面板按钮布局，统一远程操作用语为 Fetch / Pull / Push。
- 调整工具图标位置，避免遮挡终端滚动条；限制远程终端网格尺寸。
- 复用 CLI v0.1.6 的配对有效期、凭据保护、文件访问边界、Git 取消和工作区资源限制修复。
- 更新前端生产依赖及 Rust ZIP、TLS/XML 等依赖，修复已知安全问题。

## 升级提示

- 从 [GitHub Releases](https://github.com/JackyZhang8/relaycat-core/releases) 或 [RelayCat 下载站](https://cdn.relaycat.cn/) 获取对应平台安装包，也可使用应用内更新功能。
- GUI 版本为 `0.2.0`，复用的 CLI 核心版本为 `0.1.6`；两端使用独立版本号。
- 若配对凭证已超过 24 小时，请重新创建会话并扫码配对。
