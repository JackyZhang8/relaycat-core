# RelayCat GUI v0.2.1

发布日期：2026-11-11 · Tag：`relaycat-gui-v0.2.1` · 对比版本：v0.2.0

本次更新修复长时间运行后的终端显示和 App 连接问题，完善工作区文件导航，并统一代码高亮体验。

## 终端与长任务连接

- 移除 WebGL 终端渲染插件，使用默认终端渲染器，修复长时间运行后乱码、需要缩放窗口才能恢复的问题。
- 集成 CLI v0.1.7：取消 24 小时配对凭证过期限制，支持运行多天后重连或重新扫码；隔离共享 Shell 异常，避免影响主终端及 Relay 消息处理。
- 放大工作区入口图标与点击区域。

## 文件浏览与 Markdown 导航

- 同级文件和文件夹左侧对齐，子目录统一缩进；展开和折叠文件夹使用不同图标。
- 文件右键菜单新增复制路径，成功后短暂显示“已复制”；文件列表顶部新增在系统文件管理器中打开项目目录的按钮。
- Markdown 中指向项目内其他 Markdown 文件的链接可直接打开，校验路径边界。
- 预览工具栏右侧新增前进、后退按钮，记录成功打开的文件并恢复预览模式与滚动位置；切换项目时清理导航历史。

## 代码高亮与 Git 历史

- 源码、Git Diff 和 Markdown 代码块统一使用 Shiki，GitHub Dark / Light 配色随 GUI 主题切换。
- 在后台按需加载语言，先显示文本；未知语言、过大内容、解析失败或超时时降级为纯文本，保留 Markdown 内容消毒。
- Git 历史滚动到底部自动加载更多；追加加载失败时保留已有记录，提供重试入口。

## 发布与升级

- macOS 公证票据装订遇到服务暂时不可用时最多尝试 5 次；其他错误仍立即中止发布。
- 从 [GitHub Releases](https://github.com/JackyZhang8/relaycat-core/releases) 或 [RelayCat 下载站](https://cdn.relaycat.cn/) 获取对应平台安装包，也可使用应用内更新功能。
- GUI 版本为 `0.2.1`，复用的 CLI 核心版本为 `0.1.7`；Relay server 保持 `0.1.3`。
- 旧版运行中的会话不会自动应用核心修复；请先保存任务，再退出旧版并启动新版 GUI。
