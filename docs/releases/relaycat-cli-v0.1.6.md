# RelayCat CLI v0.1.6

发布日期：2026-10-24 · Tag：`relaycat-cli-v0.1.6` · 对比版本：v0.1.5

本次更新重点提升更新链路、扫码配对与远程工作区的安全性和稳定性。

## 更新与安全

- 正式发布构建支持 Ed25519 更新清单签名验证，签名绑定版本、目标平台与 SHA-256 摘要，防止更新记录被替换。
- 自定义更新清单仅下载并校验文件，不再自动替换当前程序；支持自替换的更新采用同目录暂存和原子重命名。
- 配对凭证有效期为 24 小时；过期后拒绝新的配对握手和旧凭证恢复，不再展示过期链接或二维码。
- 配对链接限制 Relay 地址为 ws/wss，并正确编码查询参数；握手拒绝低阶公钥及未定义的协议版本。
- 配对材料、配置和最近会话采用原子写入；收紧日志、二维码和私有文件权限，补齐 Windows ACL 限制，拒绝日志符号链接。
- 输入诊断与调试输出进一步脱敏，避免泄露输入内容、密钥和配对材料。

## 工作区与稳定性

- 限制目录扫描、文件读取、缩略图解码、未跟踪目录删除、事件队列和并发请求的资源消耗。
- 加固文件访问与符号链接处理，限制嵌套 Git 仓库的操作范围。
- Git 取消请求可中断排队和执行中的任务；超时后回收子进程组，避免命令长期挂起。
- 修复工作区操作的幂等缓存与操作编号处理，失败结果不再缓存。
- 限制终端控制序列缓冲区，改善异常配对帧及锁中毒情况下的错误处理。
- 更新 ZIP 等依赖锁定版本，修复已知依赖安全问题。

## 升级提示

- 从 [GitHub Releases](https://github.com/JackyZhang8/relaycat-core/releases) 或 [RelayCat 下载站](https://cdn.relaycat.cn/) 获取对应平台安装包，安装后运行 `relaycat --version` 确认版本为 `0.1.6`。
- 若旧配对凭证已过期，请重新创建会话并扫码配对。
- 自行构建需在构建时注入 `RELAYCAT_CLI_UPDATE_PUBLIC_KEY` 才能启用签名校验；正式发布流程还要求配置匹配的 `RELAYCAT_CLI_UPDATE_SIGNING_KEY`，详见 [CLI README](../../relaycat-cli/README.md#cli-update-signing)。
