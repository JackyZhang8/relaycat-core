安全与加密

          
    
            
  • 端到端加密：X25519 密钥协商，输入与终端输出全程加密，仅你的设备能解密。
    • 
            
  • Relay 只做中转：仅转发加密数据，不解密、不存储任何业务内容。
    • 
            
  • 本地执行：命令在你自己的电脑上运行（本地 PTY），代码与凭据不离开本机。
    • 
            
  • 扫码配对：一次性配对材料，支持多会话恢复，配对二维码请勿外发。

    欢迎使用 RelayCat
    
            
    
              在手机上安全远程操控本地电脑里的 Claude Code、Codex、OpenCode 和 Shell——查 Bug、跑测试、审批操作，不必守在电脑前。
            
    
            
      
              
    • 端到端加密，Relay 只中转不解密，代码与凭据不离开本机。
      • 
              
    • 扫码即连，约 3 步、几分钟即可开始第一段会话。
      • 
            
    
          
    

          
    
            
    三步连接手机
    
            
      
              
    1. 在手机上安装 RelayCat App（iOS / Android）。
      2. 
              
    2. 在电脑上「新建会话」，选好工具与项目目录，填入 Relay 地址。
      3. 
              
    3. 用手机扫描弹出的配对二维码，即可实时镜像、双向输入。
      4. 
            
    
            
          
    

          
    
            
    快速设置
    
            
    
              
              
              
    
                已为你填好官方中转地址 wss://001.relaycat.cn，开箱即用。官方中转在高峰期可能拥挤，你也可以自建专属 Relay 获得更稳定的连接；之后可在「设置」里随时修改。
                想自建 Relay 服务器？查看教程 →
              
    
            
    
            
    
              点击「下一步」检测本机可用的 AI 编码工具。
            
    
          
    

          
    
            
    检测本机工具
    
            
    
              RelayCat 在手机上接管这些本地工具。已安装的可直接使用；未检测到的可点右侧「安装教程」按提示装好后回来即可。
            
    
            
      
            
      
              没装齐也没关系——先用「Shell」体验，之后随时安装其它工具。点击「开始使用」创建第一段会话。
